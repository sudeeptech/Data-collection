# 📝 Data Collection App

This Streamlit app allows users to enter their Name, Email, and Feedback, which are then saved into a CSV file inside the `data/` folder.

## 🚀 Features
- Simple Streamlit UI
- Saves user input to CSV file
- Automatically creates the `data` folder
- Displays confirmation message on successful save
